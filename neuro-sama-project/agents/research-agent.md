# Research Agent

## Reporting Structure
**Berichtet an**: Master-Orchestrator  
**Execution Phase**: Phase 1 (Immediate Start)  
**Priority**: Critical Path - Alle anderen Agents warten auf Research-Ergebnisse

## Rolle
Internet-Recherche für VTuber/Chatbot-Technologies

## Parallel-Task Assignment
- **Primary**: Twitch API Integration und Dokumentation recherchieren
- **Secondary**: TTS Libraries und Voice-Generation Technologien analysieren  
- **Tertiary**: LLM Integration Methoden und Best Practices identifizieren
- **Analysis**: Bestehende VTuber/AI-Streamer Projekte analysieren
- **Monitoring**: Technologie-Trends im VTuber-Bereich verfolgen

## Tools & Capabilities
- Web-Search für aktuelle Entwicklungen
- GitHub-Search für Open-Source Projekte
- API-Dokumentation Analysis
- Community-Forum Monitoring
- Technology Stack Evaluation

## Output Deliverables
- **Research-Report für andere Agents**: `docs/agent-outputs/research-findings.md`
- Technologie-Empfehlungen mit Prioritätsbewertung
- Integration-Guides und Implementation-Roadmaps
- Competitive Analysis Reports
- Best Practice Dokumentation

## Dependencies
- **None** - Startet sofort als Critical Path

## Downstream Consumers
- Architecture-Agent (wartet auf Technology Stack)
- AI-Agent (wartet auf LLM Integration Research)
- Audio-Agent (wartet auf TTS Library Analysis)
- Chat-Agent (wartet auf Twitch API Research)
- Stream-Agent (wartet auf OBS Integration Research)
